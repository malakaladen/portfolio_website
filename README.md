## 🌌 Overview

This is my personal portfolio, built to present my development journey and selected university and personal projects. The website includes an introduction, an about section, a technical skills overview, featured projects, an online resume, and contact options.

## ✨ Features

- Responsive personal portfolio layout
- About me and technical skills sections
- Featured project cards with technology tags
- Dedicated resume page and downloadable CV
- Contact links and a message form
- Smooth section navigation and scroll animations

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — styling, responsive layout, and animations
- **JavaScript** — interactive behavior
- **Devicon** — technology icons
- **Formspree** — contact form handling

## 🚀 Run Locally

No package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/malakaladen/portfolio_website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

For a better local development experience, you can use the **Live Server** extension in Visual Studio Code.
